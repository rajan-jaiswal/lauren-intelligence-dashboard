Overview Page — Enterprise Redesign

Complete visual overhaul of OverviewPage.jsx. All 4 original rows and all 11 sections are preserved — nothing removed. Layout, hierarchy, spacing, and information density have been made enterprise-grade.

  • Hero identity bar added at top: Product name + category / deployment / market position badges + 4 live KPI tiles (Win Rate, Customers, TCO Advantage, Competitors Tracked) — all derived from existing data with no new API needed
  • SectionLabel component: Consistent coloured accent-bar headers across all 11 sections — replaces uppercase raw card-title styling with a structured, scannable hierarchy
  • Competitor cards: Left-colour-border per competitor, tighter layout, market position badge inline with name — much cleaner than the old flat card
  • Objection Handling: Two-tone cards — orange band for objection (speech-bubble style) + grey response band — visually separates customer voice from rep response
  • Case Studies: Colour-tinted Result section per study type, cleaner Challenge/Result vertical flow within each card
  • Feature tiles: JS hover state (border + background highlight) on Key Feature grid — adds interactivity feel without any extra library
  • Win/Loss KPIs: Colour-tinted individual stat tiles (green for Won, red for Lost, blue for Win Rate) instead of uniform grey
  • AI Coach card: Blue left-border quote block for customer voice, yellow highlight block for recommended case study
  • TCO bars: Slightly taller (20px), smooth CSS transition on width render
  • Feature Matrix: Dot indicators sized to 12px (was 10px), product column header in bold blue — much easier to read at a glance
  • Typography: Increased from 9–10px micro-labels to 10.5–11px — readable without zooming

Global CSS Polish — index.css

Targeted additions that lift the entire dashboard, not just the overview page.

  • Table alternating row backgrounds (:nth-child(even)) — easier row scanning
  • Table row hover state uses blue-lt tint — clear active row highlight
  • Card hover border brightens to blue tint — adds subtle depth to the card grid
  • New utility classes: .obj-card, .obj-objection, .obj-response, .kpi-hero-tile

Biggest single improvement: Full Page-Based Navigation

Currently every sidebar click renders a separate full page — which is already in place. The opportunity is to give each page more breathing room: full viewport height with its own scroll, no more fixed-height card cramming. This alone will make every page feel like a professional enterprise tool rather than a compact card view.

UX — Objection Handling Page

Searchable / Filterable Battle Cards

Add a search input above the objection cards so sales reps can type a keyword ("price", "security", "compliance") and see only relevant objection/response pairs. Zero backend changes needed — client-side filter on the existing data array.

Data Completeness Indicator

Show a "profile completeness" percentage per product in the sidebar or filter bar: how many of the 11 data sections have non-empty content. Flags to admins which products need enriching before they go into a sales call.
